# Revisión abierta

MakerIDE es una beta gratuita que se mejora de forma progresiva.
La [checklist de 227 controles](CHECKLIST.md) permite seguir el trabajo y colaborar;
no representa 227 pruebas superadas ni una lista de leyes aplicables automáticamente.

**Estado:** hay evidencias parciales y tareas abiertas. Las pruebas de una versión,
un equipo o un experimento local no certifican todas las descargas.

- [Licencia propia](../LICENSE) y [avisos de terceros](../THIRD_PARTY_NOTICES.md).
- [Seguridad y comunicación de vulnerabilidades](../SECURITY.md).
- [Condiciones para distribuir nuevas versiones](../docs/RELEASE_POLICY.md).

## Límites de esta revisión

El titular declara un proyecto personal gratuito, sin ingresos ni uso empresarial.
Revisaremos la aplicabilidad si cambia el uso o la distribución. Esto no modifica MIT
ni sustituye derechos, contratos, licencias o normas que sí resulten aplicables.

La RC4 histórica mantiene la [incidencia #11](https://github.com/msrobotika/AB-MakerIDE-SUPER/issues/11)
abierta. Continúan pendientes la revisión completa de paquetes, recursos y firmware,
privacidad/retención, condiciones de IA y otros controles. Las buenas intenciones
acompañan las correcciones y las evidencias; no se usan como garantía jurídica.

## Notas para interpretar la checklist

- Las prioridades P1/P2/P3 orientan el trabajo. Un servicio de pagos, una base de datos
  o una función comercial se evalúan si existen; no se añaden solo para marcar una casilla.
- Las menciones técnicas de marcas deben respetar sus reglas; no se afirma afiliación.
- El calendario y las obligaciones de IA se revisan según función, rol y norma vigente;
  no se atribuye automáticamente a un editor toda obligación de un proveedor de modelos.
  [Reglamento europeo de IA](https://eur-lex.europa.eu/eli/reg/2024/1689/oj).
- El propósito y la actividad importan para CRA; ser gratuito no resuelve toda evaluación.
  [Orientación oficial sobre software libre](https://digital-strategy.ec.europa.eu/en/policies/cra-open-source).

No se ofrece un dictamen ni una certificación. Se conserva un seguimiento público
honesto para que los usuarios sepan qué está disponible y qué falta por revisar.
