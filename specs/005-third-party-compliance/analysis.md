# Análisis de riesgos
La CLI Arduino se ejecuta externamente, GPLv3 y condiciones de uso comercial documentadas por su titular; no existe permiso implícito para redistribuirla. Las librerías de los sketches se instalan fuera del repositorio. Scaffolding Spec Kit MIT de GitHub está incluido con licencia original.

No se reescriben tags, hashes ni evidencias de firmware antiguo. El ejemplo renombrado conserva mecánicas arcade pero no existe auditoría jurídica exhaustiva de todo asset, ni nueva prueba de hardware. La CI cubre regresión técnica y **no** equivale a certificación legal.
