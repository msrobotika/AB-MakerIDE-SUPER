# Higiene de marcas y licencias — AB MakerIDE SUPER

## Alcance
Limpiar identidades del ejemplo arcade mantenido, atribuir terceros correctamente, proteger futuras distribuciones sin tocar tags o Releases.

## Requisitos
- **FR-001**: El código de desarrollo del juego será Defensa Orbital y no usará identificadores de otra franquicia, con historia RC4 intacta.
- **FR-002**: Inventario documentado de licencias MIT propia, MIT de Spec Kit de GitHub y GPL-3.0 externa de Arduino CLI con límites claros.
- **FR-003**: Marcas e independencia explícitas en los README español/inglés, sin afirmar certificación ni respaldo de proveedores.
- **FR-004**: Test unitario anti-regresión, hashes de archivos técnicos y Spec Kit coherentes, sin crear Release ni modificar firmware histórico.

## Fuera de alcance
Análisis jurídico formal, titularidad probada de todos los recursos, certificado de firmware renombrado o instalación de Arduino CLI.
