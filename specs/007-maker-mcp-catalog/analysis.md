# Análisis de alcance y riesgos
**Integración = configuración, no conexión viva.** REA 6.8.0 se ejecutaría posteriormente por npx desde una tarea autorizada; requiere Node y potencialmente descompilador Ghidra. Context7 consulta servicio remoto del proveedor; la cuenta gratuita puede limitarse y puede enviar código/contexto. Playwright 0.0.83 usa --headless --isolated; es separación de cookies, NO sandbox de sistema/red. Los MCP pueden ejecutar acciones sobre los archivos o dispositivos si el usuario los permite; agentes en modo autónomo/total no son aislados. 
Los servidores candidatos KiCad, ESP32 docs, debugger, Serial, Filesystem y GitHub no tienen comandos instalables en esta entrega, evitando nombres/versiones inventados. La CI no instala npm de terceros, no usa cuentas y no analiza ni flashea hardware; valida únicamente rutas, protección y estado opt-in.
La configuración personal de Codex en el PC no es accesible vía GitHub. El script prepara una revisión antes de cualquier cambio y no se ejecuta en esta PR.
