# Coherencia

La rama pública no contiene los parches locales de arranque, privacidad IA ni el
motor Cuttlefish. Publicar la rama local completa violaría el alcance: se trasladan
solo textos revisados sobre origin/main. No se importan sus pruebas como resultados
del código público. El archivo histórico conserva el texto previo sin presentarlo
como la guía vigente. La checklist informa y permite contribuir; sus pendientes no
bloquean compartir esta documentación ni certifican una distribución de software.
