# Criterios comprobables

- [x] Ejemplo renombrado no reutiliza evidencia del firmware histórico.

- [x] Detecta nombres de ejecutable Arduino CLI y ejemplo antiguo.
- [x] Pruebas de regresión integradas en suite de unitarios.
- [x] No se genera ni sustituye una Release.
