# RC4: presentación verificable y marca genérica para la demostración arcade

Objetivo: completar la presentación de RC4 con capturas reales, una ficha entendible y una referencia de videojuego sin apariencia de producto oficial. Proteger la trazabilidad de las pruebas ya publicadas, sin crear otra Release ni modificar los paquetes RC4.

## Requisitos comprobables

- **FR-001**: La portada ES y EN debe mostrar al menos dos capturas **reales** del IDE RC4 enlazadas a sus evidencias y sin presentar imágenes antiguas como RC4.
- **FR-002**: La nueva presentación de RC4 debe contener descarga, instalación, características verificadas, limitaciones y pruebas reales/controladas diferenciadas, lista para incorporarla a la ficha sin crear RC5.
- **FR-003**: La demostración de naves debe denominarse genéricamente; en el código posterior a RC4 el título mostrado es «Defensa orbital» y no utiliza el título de un videojuego comercial. Los hashes/logs históricos se consultan desde el tag RC4 sin reescribir evidencia.
- **FR-004**: El control Spec Kit debe cubrir también archivos Arduino `.ino` y C/C++ `.h`, `.hpp`, `.c`, `.cpp` con sus hashes y test dedicado.

## Límites

No se cambian el tag, la descripción de Release ya publicada, los adjuntos ZIP/MP4 ni las pruebas históricas de hardware. La conexión GitHub disponible no permite modificar Releases: es necesaria una edición de la ficha por el propietario desde la UI para incorporar las capturas y el texto preparado. No se garantiza ausencia de riesgos de propiedad intelectual por cambio de título: revisar también arte, sonido y licencias antes de una distribución comercial.
