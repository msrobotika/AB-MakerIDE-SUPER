# Convergencia

Se cumple el objetivo de presentar trabajo real del agente sin duplicar la lógica de ejecución. El panel no permite invocar herramientas ajenas al flujo existente. Las pruebas unitarias verifican las inferencias legítimas y rechazan afirmar estados de hardware no observados. Chromium controlado comprueba el mismo consentimiento que el panel tradicional.

La validación de una CLI instalada y una placa física es posterior y se registra separadamente. "Compilación observada" no equivale a "programa en pantalla funcionando". La integración queda condicionada a CI, manifiesto SHA-256 y revisión de PR. Sin lanzamiento hasta hito autorizado.
