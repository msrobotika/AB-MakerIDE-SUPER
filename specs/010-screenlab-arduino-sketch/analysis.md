# Riesgos y límites
Se usan los perfiles ya presentes en ejemplos físicos IdeaSpark ST7789 y CYD ILI9341; ninguna nueva identificación automática. Bibliotecas Adafruit externas al IDE. CYD conserva SD deseleccionada y no inicializa táctil. Ambos dibujos contienen botones **decorativos** sin acciones GPIO, sensores, red ni control industrial. La imagen se dibuja una vez y permanece en pantalla. Caracteres no ASCII pueden transliterarse. MotionLab en este backend se rechaza, no se simula su funcionamiento.

La compilación auténtica en Arduino CLI con núcleo ESP32 3.3.12 y librerías instaladas debe verificarse por log de GitHub. Ni siquiera eso acredita revisión física, rotación real, backlight en todas las variantes o interacción táctil. El IDE exige FQBN ESP32, consentimiento y copia anterior para transferir; no flashea ni compila automáticamente. Futuro: ciclo físico con respaldo, autorización y fotografías, calibración táctil CYD y proyecto LVGL completo. Sin nueva Release.
