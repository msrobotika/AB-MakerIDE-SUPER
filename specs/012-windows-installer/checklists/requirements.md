# Criterios de entrega
- [x] Binario de aplicación compilado con Python integrado y recursos declarados.
- [x] Instalación sin elevación y directorio de datos separado de la aplicación.
- [x] Control CI de diagnóstico, HTTP, desinstalación y preservación de usuario definido.
- [x] Publicación condicionada a permiso explícito y comprobaciones aprobadas.
- [x] Limitaciones sobre firma, MCU, proveedores y Arduino CLI visibles.
