# AB MakerIDE SUPER · MS Robotika

**Free, open-source beta for Arduino, ESP32 and MicroPython projects.**
This is an evolving project: documented tests and known limitations are part of its development.

- Edit, save and import firmware projects.
- Compile, upload and use the serial monitor with the required external board tools.
- Explore ScreenLab/MotionLab and optional AI/MCP integrations using your own accounts and permissions.

**[Download Windows x64 TEST](https://github.com/msrobotika/AB-MakerIDE-SUPER/releases/download/windows-test-dev-025dd26e85/AB-MakerIDE-SUPER-Windows-x64-dev-025dd26e85-Setup.exe)**
· [Checksums and package evidence](https://github.com/msrobotika/AB-MakerIDE-SUPER/releases/tag/windows-test-dev-025dd26e85)

The unsigned TEST installer includes Python. Arduino CLI, board cores and AI credits are not bundled.
Read the [installation/version guide](docs/DESCARGAS_Y_VERSIONES.md), verify the download source and checksum,
save your projects and confirm the board before replacing its firmware.

The TEST download, main source and local experiments can differ. **Cuttlefish is not integrated into this public source or the download yet.**
Historical RC4 retains an [open distribution audit (#11)](https://github.com/msrobotika/AB-MakerIDE-SUPER/issues/11).
Generating code, compiling, verifying uploaded bytes and observing working hardware are separate results.
